# templates

แม่แบบของโน้ตแต่ละชนิด (SPEC ภาคผนวก A) — คัดลอกไปที่โฟลเดอร์ปลายทางแล้วแทนค่าใน `<...>` และ `YYYY-MM-DD`

| ไฟล์ | ใช้กับ |
|---|---|
| [knowledge-note.md](knowledge-note.md) | knowledge note (system / entity / field / rule / query / dq / glossary) |
| [task-card.md](task-card.md) | task card และ prompt card |
| [handoff.md](handoff.md) | handoff |
| [run-log.md](run-log.md) | run log ของ Conductor |
| [adr.md](adr.md) | decision (ADR) |
| [brain.yml](brain.yml) | manifest ของ work repo |

ค่าเริ่มต้น `classification: internal` เหมาะกับ instance — ในแม่แบบ (master) ใช้ได้แค่ `public`
