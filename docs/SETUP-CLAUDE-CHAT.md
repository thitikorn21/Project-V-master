# เชื่อม Brain กับห้องคิด (Claude chat) แบบอ่านอย่างเดียว

ห้องแชทคือ **Channel** ใน SPEC §2 — ใช้คิด ปรึกษา อ่านความรู้ใน Brain แต่ **ไม่เขียนกลับ**
ถ้าคุยแล้วต้องแก้ Brain ให้ทำ **prompt card** (SPEC §2.1) ส่งต่อให้ agent ที่ทำงานผ่าน PR

ตรวจจากศูนย์ช่วยเหลือของ Claude เมื่อ 2026-11-27: https://support.claude.com/en/articles/10167454-use-the-github-integration

## เชื่อมครั้งแรก

ใช้กับ instance ที่เป็น private ได้ (ไม่ต้องใส่ชื่อ repo จริงลงไฟล์ใดๆ)

**ในแชทธรรมดา**
1. กดปุ่ม **+** มุมซ้ายล่างของช่องพิมพ์ → **Add from GitHub**
2. ถ้ายังไม่เคยเชื่อม ระบบจะพาไปหน้า GitHub ให้ยืนยันสิทธิ์ (repo private ต้องให้สิทธิ์ผ่าน GitHub App ของ Claude)
3. เลือก repo แล้วเลือกเฉพาะไฟล์/โฟลเดอร์ที่ต้องใช้ (เช่น `governance/`, `knowledge/`, `PRINCIPLES.md`)

**ใน Project**
1. ในส่วนความรู้ของ Project กดปุ่ม **+** → **GitHub**
2. ค้นหา repo หรือวาง URL แล้วเลือกไฟล์

## ข้อจำกัดที่ต้องรู้

| เรื่อง | สิ่งที่เกิดขึ้น | ทำอย่างไร |
|---|---|---|
| ข้อมูลไม่อัปเดตเอง | ห้องแชทเห็นไฟล์ ณ ตอนที่ sync ล่าสุด | กดไอคอน **Sync** (หรือ **Sync now** ใน Project) หลัง merge PR ทุกครั้ง |
| อ่านได้ทีละ branch | sync เฉพาะไฟล์ใน branch เดียว ไม่เห็นประวัติ commit หรือ PR | ให้ใช้ `main` เป็นหลัก เพราะเป็นความจริงที่ผ่านการตรวจแล้ว |
| ขนาด | ไฟล์ที่เลือกต้องพอดีกับ context ของห้องแชท | เลือกเฉพาะโฟลเดอร์ที่ใช้ อย่าเลือกทั้ง repo |
| ไม่ใช่การเขียนกลับ | ตัวเชื่อมนี้ใช้อ่านเนื้อหา ไม่มีขั้นตอนเขียนกลับ repo | การแก้ทุกอย่างผ่าน prompt card → agent → PR |

> เอกสารทางการอธิบายแต่การอ่าน ไม่ได้ระบุชัดว่าห้ามเขียน — มาตรฐานนี้กำหนดเองว่า Channel อ่านอย่างเดียว
> วิธีเลือก branch ไม่ได้ระบุในเอกสาร ให้ตรวจบนหน้าจอตอนเลือก repo

## วิธีส่ง prompt card จากห้องแชท

1. ในแชท ขอให้ช่วยร่าง task card ตาม `templates/task-card.md` โดยตั้ง `status: inbox` และ `created_by: channel`
2. คัดลอกข้อความที่ได้ ส่งให้ agent ที่ทำงานกับ repo (เช่น Claude Code) พร้อมบอกว่า "บันทึก prompt card นี้ลง `work/tasks/` ผ่าน PR"
3. agent ทำตาม routing (`governance/routing.md`) และส่งผลกลับเป็น PR + handoff ให้คุณรีวิว

ห้ามวางความลับ (รหัสผ่าน, token) ลงในแชทหรือใน prompt card
