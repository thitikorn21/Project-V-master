# governance/local — การตั้งค่าเฉพาะ instance

โฟลเดอร์นี้เป็นที่ของสิ่งที่ **แต่ละ instance กำหนดเอง** เช่น

- ชื่อเรียก role แบบเฉพาะของทีม (ชื่อธีม, ชื่อเล่นของ agent) และการผูก role กับเครื่องมือจริง
- ผลการตรวจนโยบายข้อมูลของผู้ให้บริการโมเดลที่ instance ใช้
- ค่าเริ่มต้น `review_after` ต่อ type ของโน้ต

กติกา:
- ในแม่แบบ (master) โฟลเดอร์นี้มีแค่ไฟล์นี้ **ห้ามใส่การตั้งค่าของ instance ใดๆ ในแม่แบบ**
- ใน instance ไฟล์ในนี้เป็น governance เหมือนกัน — มนุษย์แก้เท่านั้น
- `scripts/upgrade-core` ไม่แตะ `governance/` ทั้งโฟลเดอร์ (รวม `local/`)
